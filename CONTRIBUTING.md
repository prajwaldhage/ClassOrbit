# Contributing to ClassOrbit

Thank you for contributing!

## Branches

- `main` - Stable branch
- `develop` - Development branch

## Branch Naming

```
feature/ORBIT-XX-description
bugfix/ORBIT-XX-description
hotfix/ORBIT-XX-description
```

## Commit Messages

Use the Jira issue key.

Example:

```
ORBIT-18 Add CONTRIBUTING.md
```

## Pull Requests

- Keep PRs small.
- Link the Jira issue.
- Merge into `develop`.

## Coding Standards

- Write clean code.
- Use meaningful names.
- Update documentation when required.
